# Issue Tracker

Issues for this repo live in **GitHub Issues**.

Use `gh issue create --repo albachteng-lab/airgradient` to file new issues.

## Workflow

- Label new issues `needs-triage` until a human triages them.
- `ready-for-agent` — autonomous agent can pick up and implement.
- `ready-for-human` — requires human review or decision.
- `needs-info` — blocked on more information.
- `wontfix` — explicitly decided not to implement.

## PRs

- Open a PR for every agent-driven change; link the issue in the PR body.
- Apply the `done` label when opening the PR; close the issue when the PR merges.
